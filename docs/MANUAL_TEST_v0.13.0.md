# 實機測試 v0.13.0（P13 相簿、點連結加入）

> 兩支手機都裝 v0.13.0。

1. **點連結加入**（最重要）：A 手機 設定 → 家庭群組 → 邀請 →「分享連結」傳到 LINE 給 B。B 在 LINE 點連結：
   - 理想：直接開 PetDiary 並問「加入家庭群組？」。
   - 若停在網頁：按「用 PetDiary 開啟」。都不行時按「複製邀請連結」，到 App 貼上。
   - 請告訴我實際是哪一種情況。
2. **擁有者通知**：B 加入後，A 收到「（B 的名字）已加入家庭群組」通知。
3. **相機掃 QR**：B 用相機掃 A 的 QR，也是開 App（現在 QR 內容是 https 連結）。
4. **相簿分頁**：底部變成 寵物 / 行事曆 / 相簿 / 統計。照片依月份排列、可只看某隻；「檔案」分頁有 PDF。點照片 →「看紀錄」「下載」「分享」。家人剛上傳的照片先顯示雲朵，稍後出現。
5. **提醒清單**：行事曆右上角鈴鐺 → 提醒清單（新增、完成、編輯都和以前一樣），左上 ← 回行事曆。
6. **新增提醒的寵物**：選到的有 ✓；只剩一隻時點它不會取消。
7. **行事曆版面**：月曆上方沒有寵物色塊了，右上角「篩選」可勾選要看的寵物；下方清單變大。摺疊 / 攤開都看一下。
