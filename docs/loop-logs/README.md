# Loop Log

每一輪 loop（自動開發循環）結束時，新增一個檔案，記錄這一輪做了什麼、測試結果、還有什麼待修正。

- 檔名格式：`YYYY-MM-DD-NN-<簡短主題>.md`，例如 `2026-10-20-01-p0-skeleton.md`
- `NN` 是當天的第幾輪（01、02……）
- 下方的 `INDEX` 每輪更新一行，方便快速瀏覽

## 範本

```markdown
# Loop YYYY-MM-DD-NN：<主題>

- 階段：P?
- 對應 commit：<hash 列表>
- 結果：✅ 通過 / ⚠️ 部分通過 / ❌ 失敗

## 這次修改了什麼
- ...

## 測試結果
| 測試清單 ID | 結果 | 備註 |
|---|---|---|
| C-01 | ✅ | |
| P1-02 | ❌ | 存檔按鈕沒有被停用 |

- 自動測試：通過 X / 失敗 Y / 略過 Z
- 截圖：`docs/loop-logs/screenshots/<檔名>`（如有）

## 待修正 / 已知問題
- [ ] ...

## 下一輪要做什麼
- ...

## 需要你決定的事（如有）
- ...
```
