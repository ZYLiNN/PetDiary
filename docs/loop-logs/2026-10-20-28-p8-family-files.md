## 這次做了什麼
- **D55 改用伺服器時間**：每次上傳由雲端蓋 `serverUpdatedAt`，規則強制等於請求時間；本機用 `sync_meta`（資料庫 v7）記錄上次同步的版本，有未上傳修改的資料不被覆蓋。修了兩個同步競態：上傳被中途取消會重送舊版本、套用雲端資料的「檢查＋寫入」被本機修改插進來（現在在同一個資料庫交易內）
- **家庭群組**：擁有者產生邀請（24 小時、一次性、`getAfter` 保證「標記已使用」與「建立成員」同一批次）；QR Code 顯示、分享連結、Google 掃描元件、貼上連結；成員列表、移除、離開、改名；加入時自己的資料一起上傳；被移除會自動回到新的私人群組
- **誰記錄的**：`Record.authorUid`（資料庫 v8），群組 2 人以上時卡片顯示
- **照片與附件上雲**：Cloud Storage `groups/{gid}/files/`；頭像與附件自動上傳 / 下載；附件清單隨紀錄文件同步；檔名檢查不允許 `../`
- **安全規則**：Firestore（members / invites）、Storage（成員、≤10MB、圖片與 PDF）共 67 個模擬器測試，已部署
- 版本 0.8.0（versionCode 9）；APK `dist/PetDiary-v0.8.0-P8-debug.apk`
