# 實機測試清單 v0.4.0（P4 提醒＋散步）— 約 15 分鐘

APK：GitHub → PetDiary → Releases → `v0.4.0-p4` → `PetDiary-v0.4.0-P4-debug.apk`
**可以直接覆蓋安裝在 v0.3.0 上**，寵物和紀錄都會保留。

提醒是這一版最需要實機驗證的功能（模擬器的鬧鐘和手機廠商的省電機制不一樣），請特別注意「準不準時」。

| # | 步驟 | 預期結果 | N6 | Fold 8 |
|---|---|---|---|---|
| 1 | 提醒分頁 → 右下「＋」新增，**這時才會**跳出通知權限詢問 | 第一次新增提醒時才問；選「允許」 | | |
| 2 | 新增一個 **3 分鐘後**的提醒（類型、名稱、時間自選） | 存檔後出現在列表的「今天」 | | |
| 3 | 關掉 App（從最近使用的 App 滑掉），等時間到 | 跳出通知「寵物名：名稱」，時間誤差在 1 分鐘內（記下實際誤差） | | |
| 4 | 在通知上按「完成」 | 通知消失，出現「已記錄完成」；到該寵物頁看到新增了一筆對應的紀錄 | | |
| 5 | 螢幕鎖定、手機放著 10 分鐘，再測一次準時度 | 仍然準時（OPPO / Samsung 若延遲，請記下延遲幾分鐘） | | |
| 6 | 提醒頁最上方的「讓提醒更準時」卡片 | 有顯示對應品牌的設定步驟；按「開啟電池設定」會跳到系統設定；照步驟設定後按「已設定，不再顯示」 | | |
| 7 | 設定好電池白名單後重複步驟 5 | 準時度有沒有改善（請告訴我結果） | | |
| 8 | 新增「每天」重複的提醒，到主頁 | 主頁上方有「今天待辦」，勾選後消失並出現「已完成並記錄」「復原」 | | |
| 9 | 按「復原」 | 待辦回來、剛剛自動建立的紀錄也不見了 | | |
| 10 | 新增一個昨天的提醒（編輯時改日期） | 列表最上面、紅字、標示「已過期」 | | |
| 11 | 記錄一筆疫苗，填「下次日期」並勾「到時提醒我」 | 提醒頁出現對應的提醒（預設上午 9:00） | | |
| 12 | 把剛才那筆疫苗紀錄的下次日期改掉 / 取消勾選 | 提醒跟著移動 / 消失 | | |
| 13 | 寵物詳細頁，點日曆往後翻到有提醒的那天 | 日期下方有彩色空心圓圈；點進去看到提醒，右下角是「新增提醒」 | | |
| 14 | 手機**重新開機**（提醒時間設在開機之後），不打開 App | 時間到仍會通知 | | |
| 15 | 設定 → 應用程式 → PetDiary → 通知，關閉通知後打開提醒頁 | 看到「尚未允許通知」說明和「開啟通知」按鈕 | | |
| 16 | 新增提醒時拒絕通知權限 | 提醒仍存檔，出現說明視窗（前往設定／知道了） | | |
| 17 | 新增紀錄 → 散步 | 散步時間（15/30/45/60 一鍵選）、有喝水、有小便、有大便；卡片顯示「45 分鐘・有喝水・小便」 | | |
| 18 | 新增面板 | 有「散步・同上次」一鍵記錄（有散步紀錄後才出現） | | |
| 19 | 攤開手機、深色模式、字體最大 | 提醒頁、待辦、日曆標記版面正常 | | |

已知限制：統計（P5）、設定（P6）、雲端同步（P7～P9）還沒做；提醒時間在手機勿擾模式下依系統設定靜音。
