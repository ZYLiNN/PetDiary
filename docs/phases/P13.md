# P13 相簿分頁、點連結加入家庭（＋提醒寵物選擇、行事曆版面）

> 設計已確認：D73 / D80（相簿取代提醒分頁）、D79（點連結加入、通知擁有者）。另含使用者 10/21 的兩個回饋。

## 這一版
1. **相簿分頁**（底部：寵物 / 行事曆 / 相簿 / 統計）
   - 「照片」格狀、「檔案」(PDF) 清單，依月份分組，最新在上；可只看某一隻寵物。
   - 點照片放大：寵物・類型・日期時間，「看紀錄」（開那隻寵物那一天）、「下載」、「分享」。
   - 家人的照片還在下載時顯示雲朵圖示，下載完成自動出現；垃圾桶裡的紀錄不顯示。
2. **提醒併入行事曆**：行事曆右上角的鈴鐺打開「提醒清單」（原本的提醒分頁內容，← 返回）。寵物頁的今天待辦不變。
3. **點連結加入家庭**（D79）
   - 邀請連結改成 `https://petdiary-878a6.web.app/join?openExternalBrowser=1#g=…&c=…`，LINE 等聊天軟體可以點；QR Code 也是同一個連結。
   - 有裝 App：Android 直接開 PetDiary（App Links，已由 Google 驗證）並問「加入家庭群組？」。在 LINE 內建瀏覽器開啟時，`openExternalBrowser=1` 讓 LINE 改用手機瀏覽器，通常可直接跳；不行時網頁上有「用 PetDiary 開啟」按鈕與「複製邀請連結」。
   - 邀請碼在 `#` 後面，瀏覽器不會送到伺服器。網頁是固定說明頁，不收集資料、不讀寫資料庫；有安全標頭（CSP、禁止被嵌入）。
   - 舊格式 `petdiary://join?...` 仍可使用。
   - **擁有者通知**：有人加入時跳出「XXX 已加入家庭群組」，可到家庭群組移除。
4. **新增提醒的寵物選擇**（回饋 1）：選到的寵物有 ✓；至少留一隻（取消最後一隻無效）。
5. **行事曆版面**（回饋 2）：寵物篩選從月曆上方的一排色塊，移到右上角的「篩選」按鈕（勾選清單，有篩選時圖示變實心並可「全部顯示」）；格子高度 66→60dp。月曆因此往上，下方清單多出約一排色塊加 36dp 的高度。
