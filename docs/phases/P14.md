# P14 提醒留紀錄、照片左右滑、購物紀錄

> 使用者 10/22 回饋三點。1、2 照建議做；3 使用者選「多隻＝全家共用」（D84），分類可自行新增。

## 這一版
1. **自訂提醒勾完也留紀錄**（P14-01）
   - 原本只有藥物／疫苗／驅蟲／就診／美容的提醒勾完會建立紀錄；「自訂」提醒（例如剪指甲）只會關閉或排下一次（D36）。
   - 現在自訂提醒勾完會新增一筆「自訂」紀錄，名稱就是提醒名稱，可再編輯（名稱、費用、照片、備註）。
   - 完成提示改成「已完成，已記錄「剪指甲」」，復原會一起把紀錄移除。
   - 「自訂」仍不在新增紀錄面板上（只從提醒產生）；搜尋類型多一個「自訂」。
2. **照片左右滑動**（P14-02）
   - 紀錄裡的照片放大後可以左右滑，下方顯示「2 / 3」；PDF 不進入滑動（仍用其他 App 開）。
   - 相簿放大後依目前的篩選（照片分頁、某隻寵物）左右滑，「看紀錄」「下載」「分享」跟著目前這張。
3. **購物紀錄**（P14-03）
   - 新類型「購物」（靛藍色、購物車圖示）：分類（飼料／零食／玩具／保健食品／用品／其他＋自訂）、品名（選填）、金額（必填）、照片（收據）、備註。
   - 一隻寵物 → 記在那隻；同時選多隻 → **只存一筆「全家共用」**（D84），不屬於任何一隻。
   - 全家共用的紀錄：
     - 行事曆：顯示所有寵物時，在當天清單的「全家共用」底下；格子裡不畫（購物都不畫，避免月曆變亂）。只看部分寵物時不顯示。
     - 統計「費用」：選全部寵物時多一條灰色「全家共用」；只看某幾隻時不算。
     - 搜尋、相簿、CSV 匯出、垃圾桶都顯示「全家共用」；點開直接進編輯（沒有寵物頁可開）。
     - 不會出現在任何一隻寵物的頁面。
   - 統計「費用」總額下面多一行「依分類」：購物依分類、其他依類型（例：就診 NT$ 3,000・飼料 NT$ 1,200）。
   - 設定 → 自訂項目 →「購物分類」可新增／改名／刪除自己的分類；內建分類固定；購物表單也能直接「新增」。
   - 搜尋：「購物」「買」「收據」等字找得到購物；分類名稱（例如「貓砂」）也找得到。
   - CSV 多一欄「購物分類」（21 欄）。

## 資料與同步
- 資料庫 v10→v11：紀錄多 `category`；新表 `purchase_categories`。舊資料不動。
- 雲端：`groups/{gid}/categories`（同玩具規則）；紀錄多 `category`（≤64 字）。規則測試 78 個。
- 全家共用的紀錄 `petId = "family"`；規則不檢查 petId 對應寵物，舊版 App 收到「購物」類型會略過（不當機）。
- **兩支手機都要更新**：舊版 App 編輯「自訂」紀錄會出錯，也看不到購物。
