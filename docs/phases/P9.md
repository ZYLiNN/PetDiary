# P9 帳號：綁定 Google、刪除帳號 — 任務拆解

> 範圍：綁定 Google 帳號（備份與換機）、刪除雲端資料與帳號。App Check 與正式簽章經評估後**不在這一版做**（D65、D9），原因見下。

## 綁定 Google 帳號
- 匿名身分是起點（**匿名登入要一直保持啟用**）。綁定 = 把同一個雲端使用者「升級」，ID 不變、群組與資料都在原地。
- 流程：設定 →「Google 帳號」→ 綁定 → Google 帳號選擇器（Credential Manager）→ `linkWithCredential`。
- **換手機 / 重新安裝**：新手機開啟雲端同步後，按「綁定」選同一個 Google 帳號 → 該帳號已綁定另一個雲端身分 → 詢問「改用這個帳號」→ 登入後這支手機的資料與該帳號的雲端資料**合併**（本機資料一起上傳，雲端資料下載）。
- 只在畫面上顯示 Email，不寫進資料庫；不提供「解除綁定」（需求少、容易誤操作）。

## 刪除雲端資料與帳號
- 設定 →「刪除雲端資料與帳號」→ 說明並確認。
- **擁有者**：刪掉自己群組的所有資料（寵物、紀錄、提醒、補充品、邀請、成員）、Storage 檔案、群組本身；其他成員下次同步會自動回到各自的私人群組，**他們手機上的資料保留**。
- **一般成員**：只退出群組，不動家庭的資料。
- 然後刪除使用者指標與雲端帳號（需要時重新驗證 Google）；**手機上的資料不動**，同步關閉（D67）。
- 順序：先刪資料，最後才刪帳號（刪資料需要登入身分）；失敗可以重試。

## 不在這一版的
- **App Check（D65）**：Firebase 的 Play Integrity 驗證需要 App 從 Google Play 發布；我們用 GitHub 發 APK 給自己和家人，開啟強制驗證會把所有人擋在外面。現在靠安全規則（只有成員能存取、欄位白名單、大小與類型限制）＋預算警示保護。若之後上架 Google Play，再啟用。
- **正式簽章金鑰（D9）**：要先請你決定金鑰存放與備份方式（遺失就無法更新已安裝的 App），所以只列為待辦。
