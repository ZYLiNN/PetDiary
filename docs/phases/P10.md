# P10 行事曆分頁 — 設計與任務

> 使用者提案（10/20）：新增一個行事曆分頁，用大版面的月曆呈現所有寵物的紀錄與提醒，每隻寵物不同底色，點日期後下方列出誰有什麼事。

## 已確認的設計（使用者回覆）
1. **入口**：設定改成每個主分頁右上角的**齒輪**，底部分頁為 寵物 / 行事曆 / 提醒 / 統計。**搜尋按鈕保持原樣**（只是左移一格，旁邊多了齒輪；兩者各有 48dp 觸控範圍、不重疊，有測試把關）。
2. **點日期後**：方案 A——月曆在上、當天清單固定在下方（寬螢幕時清單在右側）。
3. **寵物代表色**：編輯寵物新增「代表色」（橘、白、藍、粉、綠、紫、黃、灰），新增寵物時自動配下一個沒人用的顏色，換手機會同步。
4. **日常紀錄**（餵食、散步）：格子裡只顯示小圓點；點選日期後，下方清單展開**全部**紀錄。
5. **由寵物點進去**：點清單裡的某一筆 → 開啟那隻寵物的頁面、停在那一天，只顯示那隻寵物的資料（寵物頁原本的週 / 月曆與提醒標記不變）。

## 畫面規則
- 底色＝寵物；字前面加寵物名的一個字（「雷米」「雷利」→ 米 / 利），不只靠顏色。
- 實心＝已記錄；虛線框＝還沒完成的提醒（完成後提醒消失，只剩紀錄）。
- 一天超過 2 件（寬螢幕 4 件）顯示「+N」；上方寵物色塊可單獨顯示 / 隱藏某隻寵物。
- 週日在最左；今天是圓形底色；可翻到未來看提醒；左右滑動翻月；「今天」鈕回到本月。
- 「＋ 新增提醒」帶入選到的日期；新增紀錄請到寵物頁（有一鍵記錄與類型面板）。
