# 實機測試 v0.11.0（P11 回饋調整一）

1. **相機掃邀請 QR**（v0.10.1 修正）：手機 B 用內建相機掃手機 A 的邀請 QR → 直接開 PetDiary 並問「加入家庭群組？」。
2. **行事曆新增紀錄**：點今天或過去某天 → 「＋ 新增紀錄」→ 勾兩隻寵物 → 選餵食 → 存檔；兩隻寵物那天都有紀錄。點未來某天只看得到「＋ 新增提醒」。
3. **提醒多選**：新增提醒時勾雷米和雷利、類型驅蟲、時間設 2 分鐘後 → 時間到只跳**一則**通知「雷米、雷利：驅蟲」→ 按「完成」→ 兩隻都有驅蟲紀錄、提醒消失。
4. **疫苗／驅蟲**：新增紀錄面板只有一個「疫苗／驅蟲」→ 進去切到「體外驅蟲」→ 存檔 → 紀錄顯示為驅蟲（體外）。
5. **下載 / 分享**：打開一筆有照片的紀錄 → 附件右邊「⋮」→「下載到手機」→ 到相簿的 PetDiary 資料夾看得到；PDF 下載後在「檔案」App 的 下載 / PetDiary 看得到；「分享」能傳到 LINE。點照片放大，下方也有「下載」「分享」。
6. **雲端檔案刪除**（需要雲端同步開著）：在一筆紀錄移除一張照片並存檔 → 等約 1 分鐘 → Firebase 主控台 Storage 裡那個檔案消失（檔名可在主控台依時間找最新的）。
