# 實機測試清單 v0.3.0（P3 搜尋）— 約 5 分鐘

APK：GitHub → PetDiary → Releases → `v0.3.0-p3` → `PetDiary-v0.3.0-P3-debug.apk`
**可以直接覆蓋安裝在 v0.2.0 上**，寵物和紀錄都會保留。
（P1、P2 的實機清單 `MANUAL_TEST_v0.1.0.md`、`MANUAL_TEST_v0.2.0.md` 如果還沒跑，建議一起跑。）

|---|---|---|---|---|
