# PetDiary 測試清單 v0.1（草稿，待確認）

> 用途：每個開發階段的「完成條件」。loop 自動開發時，所有項目通過才算該階段完成。
> 對應計劃書：`docs/PLAN.md`
>
> **測試方式代號**
> - `U` 單元測試：自動跑，驗證邏輯（例如年齡計算）
> - `I` 整合測試：自動跑，驗證資料庫讀寫
> - `UI` 畫面測試：自動跑，用 Compose 測試工具模擬點擊
> - `E` 模擬器驗收：Claude 在 Pixel Fold 模擬器上操作並截圖檢查
> - `M` 實機測試：你在 Find N6 / Fold 8 上手動測試
>
> **裝置狀態代號**：📱 折起（外螢幕）　📖 攤開（內螢幕）　↔️ 攤開橫放（近似寬折疊）

## P1 寵物管理

| ID | 項目 | 方式 |
|---|---|---|
| P1-01 | 沒有寵物時，主頁只顯示「＋」方格，並有一句引導文字 | UI |

| P1-05 | 年齡依生日自動計算（例如「3 歲 2 個月」、「5 個月」），跨月、閏年都正確 | U |
| P1-06 | 選填欄位：照片、性別、結紮、品種、晶片號碼、備註，都可以存和讀取 | I |
| P1-07 | 照片可以從相簿選或用相機拍，裁切成圓形顯示 | E / M |
| P1-08 | 方格右上角顯示對應類型的剪影；「其他」類型顯示腳掌 | E |
| P1-09 | 方格欄數：📱 2 欄、📖 3～4 欄 | E |

| P1-11 | 寵物資料存檔後，關掉 App 重開還在 | I |
| P1-12 | 名稱輸入 emoji、很長的名字（30 字）時，方格不會跑版 | E |

## P7–P9 雲端（之後再細寫）

- 安全規則測試：陌生人讀不到、被移出群組後讀不到、不能寫入別人的寵物資料
- 離線時新增的紀錄，連上網路後自動同步
- 兩支手機同時編輯同一筆紀錄時，衝突處理符合預期
- QR Code 過期、或已經用過的話，不能再加入群組
- 照片大小限制、每人上傳數量限制
- 綁定 Google 帳號後換手機登入，資料完整恢復
- 刪除帳號後，雲端資料確實被刪除
