# 實機測試 v0.14.1（照片縮放、加入通知修正）

> 只改照片檢視與家庭通知，資料庫沒變；兩支手機版本不同也能同步，但建議都更新。

1. **內螢幕按鈕**：攤開手機，到相簿點一張直式照片 → 下方「下載 / 分享 / 看紀錄 / 關閉」都看得到。紀錄裡的照片也試一次。
2. **點一下不關**：點照片一下 → 不會關閉；按「關閉」或返回手勢才關。
3. **縮放**：兩指捏合放大 → 單指拖動照片 → 點兩下還原。點兩下也能直接放大。
4. **放大時不換頁**：放大後左右拖只會移動照片；點兩下還原後，左右滑又能換下一張。
5. **加入通知**（擁有者的手機）：把 App 從最近使用清單滑掉再開、開關飛航模式 → 不會再跳「○○ 已加入家庭群組」。
