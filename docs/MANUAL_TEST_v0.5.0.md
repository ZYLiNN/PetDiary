# 實機測試清單 v0.5.0（P5 統計）— 約 10 分鐘

APK：GitHub → PetDiary → Releases → `v0.5.0-p5` → `PetDiary-v0.5.0-P5-debug.apk`
**可以直接覆蓋安裝在 v0.4.0 上**。（P4 提醒的實機清單 `MANUAL_TEST_v0.4.0.md` 如果還沒跑，建議先跑。）
統計需要有一些紀錄才看得出效果；可以先隨便補記幾天的餵食、體重、散步、有花費的就診 / 美容。

| # | 步驟 | 預期結果 | N6 | Fold 8 |
|---|---|---|---|---|
| 1 | 打開統計分頁 | 預設：全部寵物、本週（日～六）、餵食折線圖；每隻寵物一種顏色，下方有文字摘要 | | |
| 2 | 點寵物標籤切換 | 可複選；選到最後一隻再點，會回到全部 | | |
| 3 | 切換 週 / 月 / 年，點左右箭頭 | 標題和圖跟著變；不能往未來翻；年圖按月、月圖按天 | | |
| 4 | 選「自訂」，選起訖日期 | 起日選比迄日晚時，迄日會跟著移動；不會出現起>迄 | | |
| 5 | 切換 散步 | 折線圖；摘要有平均每天時間、有喝水 / 小便 / 大便次數 | | |
| 6 | 切換 體重 | 折線圖，縱軸貼近體重範圍；貓、狗體型差很多時有提示 | | |
| 7 | 切換 費用 | 依寵物分色的堆疊長條＋「總花費」；總額和你記的就診 / 美容費用相符 | | |
| 8 | 切換 藥物 / 疫苗 / 驅蟲 / 就診 / 美容 / 異常 | 次數長條圖；摘要有「最近一次」 | | |
| 9 | 選一個沒有紀錄的項目或期間 | 顯示「這段期間沒有…的紀錄」說明，不是空白圖 | | |
| 10 | 本週還沒到的日子 | 折線留白，不是掉到 0 | | |
| 11 | 攤開手機、橫向、深色模式、字體最大 | 圖表和文字都清楚，顏色可分辨 | | |
| 12 | 開啟 TalkBack（如果方便） | 圖表有文字說明可以朗讀 | | |

已知限制：圖表沒有「點一下顯示數值」，數值看每隻寵物下方的文字摘要；設定（P6）、雲端同步（P7～P9）還沒做。
