# 實機測試 v0.10.0（P10 行事曆分頁）

1. **底部分頁**變成 寵物 / 行事曆 / 提醒 / 統計；每個分頁右上角有齒輪，點開是設定，左上返回回到原分頁。
2. **搜尋**：寵物分頁右上角的放大鏡仍在、好點，旁邊是齒輪。
3. **代表色**：編輯寵物 → 選「代表色」；新增第二隻寵物時自動選了和第一隻不同的顏色。
4. **行事曆**：
   - 打開預設是本月、今天被選中；每隻寵物的紀錄與提醒用該寵物的顏色顯示在格子裡，字前面有寵物名的一個字。
   - 虛線框是還沒完成的提醒；餵食、散步只有小圓點。
   - 點某一天，下方列出那天所有人的所有紀錄（含餵食、散步）。點其中一筆 → 進入那隻寵物的頁面、停在那一天，只看到那隻寵物。
   - 上方寵物色塊可以只看某一隻；左右滑動或 ◀ ▶ 翻月；「今天」回本月；可以翻到未來看提醒。
5. **折疊螢幕**：攤開後月曆在左、當天清單在右；折疊 / 攤開切換時選到的日期與月份不應遺失。
6. **字體放大到 200%** 時，格子裡的文字不被切掉（太長會省略號）。
7. **雲端**：兩支手機同一群組時，寵物顏色會同步。
