# 實機測試清單 v0.1.0（P1 寵物管理）— 約 5 分鐘

APK：GitHub → PetDiary → Releases → `v0.1.0-p1` → 下載 `PetDiary-v0.1.0-P1-debug.apk`
（第一次安裝需允許「安裝不明來源的 App」）

請在 **Find N6** 和 **Fold 8** 各跑一次，有問題就記下編號和狀況（截圖更好）。

| # | 步驟 | 預期結果 | N6 | Fold 8 |
|---|---|---|---|---|
| 1 | 冷啟動：滑掉 App 後重新打開，心裡數秒 | 2 秒內出現「我的毛孩」（C-03） | | |
| 2 | 點「＋ 新增寵物」→ 什麼都不填 | 「儲存」是灰的，欄位旁有提示 | | |
| 3 | 選「貓」、輸入中文名字、選「知道生日」挑一個日期 → 儲存 | 主頁出現方格，年齡正確（例如「3 歲 2 個月」） | | |
| 4 | 再新增一隻，按「相簿」挑一張照片（P1-07） | 大頭貼變成那張照片，圓形顯示 | | |
| 5 | 再新增一隻，按「拍照」拍一張（P1-07） | 照片方向正確（不會躺著） | | |
| 6 | 填到一半 → 折起 / 攤開手機 | 已填的內容都還在（C-05） | | |
| 7 | 主頁折起 / 攤開 / 橫放（Fold 8） | 折起 2 欄、攤開 3～4 欄，左側導覽列；沒有被切掉 | | |
| 8 | 長按一隻寵物 → 編輯 → 改名字 → 儲存 | 名字更新 | | |
| 9 | 長按 → 刪除 → 5 秒內按「復原」 | 寵物回來 | | |
| 10 | 再刪除一次，不按復原 → 設定 → 垃圾桶 | 看到牠，顯示「剩餘 7 天」；按「還原」回到主頁 | | |
| 11 | 系統切換深色模式 | 畫面變深色，文字清楚 | | |
| 12 | 系統字體調到最大 | 版面不破、文字不被切掉 | | |

已知限制：「寵物 / 提醒 / 統計」以外的功能還沒做；點寵物方格目前沒有反應（P2 的詳細頁）。
