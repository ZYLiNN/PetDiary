# 實機測試清單 v0.2.0（P2 每日紀錄）— 約 10 分鐘

APK：GitHub → PetDiary → Releases → `v0.2.0-p2` → `PetDiary-v0.2.0-P2-debug.apk`
**可以直接覆蓋安裝在 v0.1.0 上**，已建立的寵物會保留（有升級測試）。

| # | 步驟 | 預期結果 | N6 | Fold 8 |
|---|---|---|---|---|
| 1 | 覆蓋安裝後打開 | v0.1.0 的寵物都還在 | | |
| 2 | 點一隻寵物 | 進入詳細頁，標題是今天，有一週月曆 | | |
| 3 | 按「＋」→ 點「餵食」→ 填份數、勾喝水、按「新增」加一個保健食品 → 儲存 | 卡片出現：「主食 1.5 份・有喝水・保健：○○」；今天有圓點 | | |
| 4 | 再按「＋」，下方有「餵食・同上次」→ 按「記錄」 | 立刻多一筆一樣的餵食；出現「已記錄餵食・復原」 | | |
| 5 | 「＋」→ 勾選第二隻寵物 → 點「驅蟲」→ 選外驅、填名稱、費用「1200」、選下次日期 → 儲存 | 兩隻寵物都有這筆驅蟲；費用顯示「NT$ 1,200」 | | |
| 6 | 「＋」→「就診」→ 附件：**拍照**一張、**相簿**選一張、選一個 **PDF** | 三個附件都列出來；儲存後卡片右側顯示迴紋針「3」 | | |
| 7 | 點那張就診卡片 → 點照片附件 / PDF 附件 | 照片全螢幕預覽；PDF 用手機的閱讀器打開 | | |
| 8 | 編輯中移除一個附件 → 儲存 → 再打開 | 只少了那一個 | | |
| 9 | 紀錄卡片往左滑 | 卡片消失，「已刪除・復原」，5 秒內按復原會回來（**5 秒夠不夠？**） | | |
| 10 | 再滑掉一筆不復原 → 設定 → 垃圾桶 | 「紀錄」區看得到它，可以還原 | | |
| 11 | 「展開整個月曆」→ 換到上個月 → 點一天 → 補記一筆體重 | 紀錄出現在那天；月曆收合 | | |
| 12 | 摘要列 | 顯示「驅蟲 今天」「就診 今天」等 | | |
| 13 | 攤開手機（Fold 8 也試橫放） | 左邊月曆、右邊紀錄；「＋」面板變成置中對話框 | | |
| 14 | 填紀錄到一半折起 / 攤開 | 已填內容都還在 | | |
| 15 | 深色模式、字體最大 | 文字清楚、不被切掉 | | |

已知限制：搜尋（P3）、提醒（P4）、統計（P5）還沒做；「到時提醒我」目前只會記下來，P4 才會真的通知。
