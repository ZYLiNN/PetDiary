# 實機測試 v0.9.0（P9 綁定 Google、刪除帳號）

安裝 `PetDiary-v0.9.0-P9-debug.apk`（debug 簽章，指紋已登錄在 Firebase；換成別的簽章就不能用 Google 登入）。

1. **綁定**：設定 → 打開「雲端備份與同步」→ 「Google 帳號」旁按「綁定」→ 選你的 Google 帳號。應顯示「已綁定：xxx@gmail.com」。
2. **換手機模擬**：在第二支手機（或把 App 解除安裝再安裝）→ 開啟雲端備份與同步 → 按「綁定」選**同一個** Google 帳號 → 出現「這個 Google 帳號已經在使用中」→ 「改用這個帳號」。幾秒內應看到原本的寵物與紀錄（照片稍後下載）；新手機上原有的資料會一起合併上去。
3. **家庭群組仍在**：換手機後「家庭群組」仍顯示原本的成員。
4. **刪除**：設定 →「刪除雲端資料與帳號」→ 確認。綁定過 Google 時可能要求再選一次帳號驗證。完成後：Firebase Console 的 Firestore / Storage 該群組資料消失，Authentication 的使用者消失；手機上的寵物與紀錄仍在，雲端同步為關閉。
5. （擁有者有家人時）刪除後，家人的手機仍保留自己看過的資料，下次同步自動改成各自的私人備份。
