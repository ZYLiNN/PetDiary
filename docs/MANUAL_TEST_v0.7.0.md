# 實機測試 v0.7.0（P7 雲端同步）

覆蓋安裝 `PetDiary-v0.7.0-P7-debug.apk`（需要網路）。

1. **開啟同步**：設定 →「帳號與家人」→ 打開「雲端備份與同步」→ 出現同意說明 → 同意。狀態應從「連線中…」變成「已開啟・上次同步 HH:mm」。
2. **上傳**：Firebase Console → Firestore Database，應看到 `groups/…/pets`、`records` 等資料。
3. **第二支手機**（若有）：安裝同一版本，但**匿名身分是每支手機各自的**，所以 P7 還看不到第一支的資料——要等 P8 的 QR 家庭群組才能共用。這是預期行為。
4. **離線**：開飛航模式新增紀錄，App 照常運作；關閉飛航模式後狀態恢復並上傳。
5. **關閉同步**：開關關閉後新增紀錄，Console 不會再出現新資料；資料不會被刪除。
6. **提醒**：重新確認 v0.4.0 的提醒清單（準時度、重開機），省電鬧鐘（D38）可能晚幾分鐘。
7. **新功能**：牽繩狗的散步圖示；提醒的「自訂」類型（黃色）；晚完成重複提醒時會問下次日期。
