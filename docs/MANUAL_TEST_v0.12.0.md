# 實機測試 v0.12.0（P12 餵食種類、玩耍、照片）

> 家庭群組的兩支手機請**一起**更新到 v0.12.0。

1. **餵食種類**：新增餵食 → 上方「種類」預設乾食 → 改選零食、填 1 份 → 存檔，卡片顯示「零食 1 份」。打開一筆舊的餵食紀錄，種類顯示乾食。
2. **玩耍**：新增紀錄面板第一排有「玩耍」→ 點 15 分鐘 → 玩具「新增」逗貓棒 → 存檔，卡片顯示「15 分鐘・逗貓棒」。再記一次時逗貓棒已經在選項裡。
3. **玩具清單**：設定 → 自訂項目 → 玩具清單，可新增、改名、刪除（刪除可復原）。
4. **統計**：餵食下方有 全部／乾食／濕食／乾濕都有／零食；選零食只算零食。統計多一個「玩耍」。
5. **照片**：散步、餵食、玩耍等紀錄也能拍照或選照片；顯示「x/10」，加到 10 個後就沒有加入按鈕。
6. **行事曆**：玩耍和餵食、散步一樣是小圓點，點日期後清單裡有。
7. **搜尋**：搜「零食」「玩具」或玩具名稱找得到。
8. **CSV 匯出**：多了「食物種類」「玩具」欄。
9. **同步**：A 手機記玩耍、新增玩具，B 手機收到。
