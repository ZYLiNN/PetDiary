# 實機測試 v0.14.0（P14 提醒留紀錄、照片左右滑、購物）

> 兩支手機都裝 v0.14.0（舊版看不到購物，編輯「自訂」紀錄也會出錯）。

1. **自訂提醒留紀錄**：新增一則「自訂」提醒（例如剪指甲，時間設今天），勾完成 → 提示「已完成，已記錄「剪指甲」」；到那隻寵物今天的紀錄，看得到「自訂・剪指甲」，點開可編輯。按「復原」紀錄會消失。
2. **照片左右滑**：一筆紀錄放 3 張照片＋1 個 PDF，點第一張放大 → 左右滑三張、下方「1 / 3」會變；PDF 不會出現在滑動裡。相簿也點一張照片左右滑，按「看紀錄」會開目前那張的紀錄。
3. **購物（一隻）**：在某隻寵物頁 ＋ →「購物」→ 選「零食」、品名、金額 → 存。寵物頁出現「購物・零食・…・NT$ …」。
4. **購物（多隻＝全家共用）**：行事曆 ＋新增紀錄 → 勾兩隻 →「購物」→ 編輯畫面上方顯示「全家共用」→ 存。
   - 行事曆當天下方有「全家共用」一組，格子裡沒有；右上篩選只看一隻時它不見。
   - 兩隻寵物各自的頁面都沒有這筆。
   - 點它會直接開編輯。
5. **自訂分類**：購物表單「分類」→「新增」→ 貓砂，自動選取；設定 → 購物分類 也看得到、可改名。另一支手機同步後也有。
6. **統計費用**：統計 → 費用：總花費下面有「依分類」一行；選全部寵物時多一條灰色「全家共用」，只點掉一隻寵物時「全家共用」消失、總額變小。
7. **搜尋**：搜「購物」「貓砂」都找得到；全家共用的結果顯示「全家共用」，點了開編輯。
8. **摺疊 / 攤開**：放大照片時摺疊 / 攤開，仍停在同一張。
